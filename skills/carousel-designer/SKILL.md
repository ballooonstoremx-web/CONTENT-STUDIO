# Carousel designer

Load the `brand-brain` skill first.

## Templates (Content HQ → Plantillas)
`portada`, `tip`, `producto` (requires real photo), `foto`, `lista`, `cta`.

## Process
1. 5–8 slides: portada with a promise → one idea per slide → cierre with CTA.
2. Headline ≤ 8 words, body ≤ 30 words per slide; checklists ≤ 7 items.
3. Any slide that names or shows a specific product uses `producto` or
   `foto` with a real library photo. If the photo is missing the web app
   blocks export; request the file instead of substituting.
4. Write the caption (hook line, 2–3 lines of value, CTA, hashtags).
5. Export ZIP from Content HQ → **Carrusel** (`slides/01.png…`, `copy.txt`,
   `ficha.json`). Set status to `revision` for owner approval.
